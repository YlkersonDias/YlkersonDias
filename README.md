## 🐹 Projeto em destaque

<a href="https://github.com/YlkersonDias/kliny"><img src="https://raw.githubusercontent.com/YlkersonDias/kliny/main/frontend/public/kliny-compartilhar.png" width="600" alt="Kliny" /></a>

**[Kliny](https://github.com/YlkersonDias/kliny)**: controle financeiro pessoal com cofres, orçamento, importação de extrato e relatórios. Construído do zero, do banco ao deploy.

- 🌐 **No ar** em [kliny.app.br](https://kliny.app.br), num servidor próprio com Docker atrás de um túnel da Cloudflare
- ✅ **740+ testes automatizados**, com o CI conferindo que uma pessoa nunca acessa os dados de outra
- 🔒 **Operações de dinheiro** idempotentes e travadas contra concorrência, CSP estrita e backups cifrados
- 🌎 **Português e inglês**, modo escuro, acessível pelo teclado e instalável no celular
